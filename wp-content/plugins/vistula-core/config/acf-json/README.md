# config/acf-json/

Secure Custom Fields (SCF) / ACF field-group definitions land here automatically
once Stage 5 (Tours CMS) and Stage 8 (Destinations) create them through the
admin UI — see `src/Fields/json-sync.php` for the save/load path wiring.

This directory is intentionally empty right now: no field groups exist yet.
Do not hand-edit files here; let SCF/ACF's Local JSON sync manage them.
